## Хамгаалалтад гарч болох асуулт

- **anon key frontend-д байх нь аюултай юу?** — Үгүй. anon key нийтийн; бүх хамгаалалтыг RLS хийдэг. `service_role` түлхүүр кодонд огт байхгүй (`.env.example`-г үзүүлнэ).
- **Хэрэглэгч өөрийгөө admin болгож чадах уу?** — `protect_profile_role` триггер хориглоно.
- **Бусдын хавтас руу зураг оруулж болох уу?** — Storage бодлого `(storage.foldername(name))[1] = auth.uid()` шалгана.
- **Оюутан устгагдвал бүтээл нь яах вэ?** — `on delete set null` — бүтээл музейд үлдэнэ.
- **is_admin() яагаад `security definer` вэ?** — profiles хүснэгтийн RLS дотор profiles-ийг дахин уншихад рекурс үүсэхээс сэргийлнэ.
- **Хайлт хаана хийгддэг вэ?** — Сервер талд: PostgREST `ilike` (нэр, тайлбар, зохиогч), `eq` (ангилал, он), `contains` (технологийн массив).
