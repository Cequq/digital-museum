# Wireframe ба хэрэглэгчийн урсгал

## Сайтын бүтэц

```
/                     Нүүр (hero, тоон үзүүлэлт, шинэ үзмэр, урилга)
├── /exhibits          Үзэсгэлэн — хайлт + ангилал/он/технологийн шүүлтүүр
│   ├── /exhibits/:id  Үзмэрийн дэлгэрэнгүй (эзэмшигчид Засах/Устгах)
│   ├── /exhibits/new        🔒 Шинэ бүтээл
│   └── /exhibits/:id/edit   🔒 Засах
├── /time-machine      ⭐ ISM Time Machine (бүтээлч шийдэл)
├── /teachers          Багш нар (хайлт + дэлгэрэнгүй цонх)
├── /events            Арга хэмжээ (төрлөөр шүүх)
│   └── /events/:id    Зурагт цомог + lightbox
├── /creators          ISM Creators — оюутан ↔ бүтээл
│   └── /creators/:id
├── /login, /register
├── /my-exhibits       🔒 Миний бүтээл
├── /profile           🔒 Профайл
└── /admin             🛡 Админ (үзмэр хянах, багш, арга хэмжээ+цомог, түүх, ангилал)
```

## Хэрэглэгчийн урсгал

```
Зочин ──► Нүүр ──► Үзэсгэлэн ──► хайх/шүүх ──► Дэлгэрэнгүй ──► Demo/GitHub
   │                    └─ илэрцгүй ──► "Олдсонгүй" мэдэгдэл + шүүлтүүр цэвэрлэх
   └──► Time Machine ──► гулсуур / ▶ аялал ──► карт ──► үзмэр/арга хэмжээ

Оюутан ──► Бүртгүүлэх ──► (и-мэйл баталгаажуулах) ──► Нэвтрэх
       ──► Миний бүтээл ──► Шинэ бүтээл (validation + зураг) ──► Storage ──► DB
       ──► Засах / Устгах (зөвхөн өөрийнх — RLS)

Админ ──► /admin ──► үзмэрийн төлөв өөрчлөх, багш/арга хэмжээ нэмэх, цомогт зураг оруулах
```
